HTML Tags I Learned

<header>
Represents the top section of a page containing title or navigation.
<nav>
Defines a section that contains navigation links.
<main>
Contains the main content of the document.
<article>
Represents self-contained content like a post or story.
<footer>
Represents the bottom section with copyright or contact info.
